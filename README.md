# Тестирование портала «Конференции.РФ»

МДК.05.03 «Тестирование информационных систем». Выполнила Хачатрян Марине Артаковна, группа 4ИСП9-45.

Тестируемое приложение: портал из МДК.09.01 (репозиторий `09.01-`, версии `v0.9` до финальной проверки и `v1.0` после исправлений).

## Задания

| Задание | Что сделано | Где |
|---|---|---|
| 1 (тема 3.1) | чек-лист на 16 пунктов, 5 тест-кейсов, 3 баг-репорта | `Отчёт МДК 05.03.docx`, `screenshots/3.1_баг-репорты` |
| 2 (тема 3.2) | анализ запроса входа и ответа сервера в DevTools | `screenshots/3.2_devtools` |
| 3 (тема 3.3) | тестирование форм регистрации и входа, классы эквивалентности, границы, негативные сценарии | `screenshots/3.3_формы`, `autotests` |

Отчёт со всеми таблицами и скриншотами: `Отчёт МДК 05.03.docx`.

## Автотесты

В папке `autotests`: Selenium, pytest, шаблон Page Object, явные ожидания, снимок экрана при падении теста.
59 проверок форм регистрации и входа и формы заявки.

```
pip install -r requirements.txt
set PORTAL_DIR=путь\к\konferencii-portal
cd autotests
python -m pytest
```

Тесты сами запускают портал во временной папке на порту 5099 и закрывают его после прогона. На версии v1.0 проходят все 59 тестов,
на версии v0.9 падают тесты, которые ловят BR-01, BR-02 и BR-03.
